# Story 1.1 — Dashboards internas Artspace

Status: Done

## Objetivo

Entregar login + dashboards (profissional e admin) com identidade visual da logo, prontas para Supabase e usáveis em modo demo até o projeto ser conectado.

## Acceptance Criteria

- [x] App Next.js (App Router) + TypeScript + Tailwind com IDV preto/ouro
- [x] `/login` autentica profissional; Maycom vê seletor Agenda | Admin
- [x] `/app` agenda com encaixe, status (confirmado, presente, faltou, remarcou), exclusão e conflito por overlap
- [x] Procedimentos com duração + preço; snapshot no appointment
- [x] Grade semanal + fechar dia isolado por profissional
- [x] Admin: financeiro (`present` por mês), profissionais, clientes, agendas alheias com banner
- [x] Schema SQL + RLS documentados para o Supabase
- [x] Cliente autenticado não entra em `/app`; profissional sem admin não entra em `/app/admin`
